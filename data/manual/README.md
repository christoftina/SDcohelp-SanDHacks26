# Team notes folder

If a website didn't scrape well (or you have info from a flyer, a phone call with an
office, or a PDF), make a .txt file here. The app loads every .txt file in this folder.

Start the file like this (first three lines are optional):

Title: San Diego Unified - How to enroll a new student
Source: https://www.sandiegounified.org/...
Topic: education

Then paste or type the information below. Only add facts from official sources.
Restart the app afterwards:  sudo systemctl restart bridgesd
